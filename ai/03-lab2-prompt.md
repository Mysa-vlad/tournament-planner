## Що агент прочитав як вхід [AI]

1. Умова «Завдання 2 — Робочий застосунок: прототип → інтеграція з БД» (Classroom): spec зі
   сценаріями, схемою БД і помилками; прототип на статичних даних через HTTP API; заміна на
   БД (транзакції, валідація, збої, ідемпотентність/ретраї); межі шарів (SQL лише в
   репозиторіях); залежності без протягування параметрів + business-process ID у кожному
   лозі; один глобальний обробник помилок; аудит (топ-3, N+1, збої); ADR на БД і залежності.
2. Рекомендації умови: явна ініціалізація пулу + `SELECT now()`, ізольоване середовище (не
   спільний `localhost:5432`), SQL tagged templates.
3. Обмеження середовища: на машині немає PostgreSQL і Docker.
