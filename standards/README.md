# Інженерні стандарти проєкту

Стандарти діють на весь курс (завдання 1–5). Кожен стандарт **захищений**: або перевіряється
автоматично (hook / скрипт), або має явний ручний пункт у [DoD](definition-of-done.md).

| Файл                                               | Про що                                      |
| -------------------------------------------------- | ------------------------------------------- |
| [spec-format.md](spec-format.md)                   | як пишеться `spec.md`                       |
| [adr-template.md](adr-template.md)                 | шаблон ADR (MADR) і правила нумерації       |
| [definition-of-done.md](definition-of-done.md)     | коли зміна вважається готовою               |
| [checks.md](checks.md)                             | перелік перевірок: що, чим, де запускається |
| [commits-and-branches.md](commits-and-branches.md) | формат комітів, гілки, PR                   |

Зміна стандарту — це теж зміна через PR із ADR, якщо вона впливає на процес.
