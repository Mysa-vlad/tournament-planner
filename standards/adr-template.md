# Шаблон ADR (MADR)

Файли: `adr/NNNN-коротка-назва.md`, нумерація наскрізна з `0001`, номери не
перевикористовуються. Відхилене/замінене рішення не видаляється — змінюється `Status`.

```markdown
# NNNN. <Назва рішення>

- Status: proposed | accepted | superseded by NNNN | deprecated
- Date: YYYY-MM-DD

## Context

Яка проблема/сила змушує ухвалити рішення. Обмеження.

## Decision Drivers

- драйвер 1
- драйвер 2

## Considered Options

1. Варіант A
2. Варіант B
3. Варіант C

## Decision

Обрано **варіант X**, тому що … (з посиланням на драйвери).

## Pros and Cons of the Options

### Варіант A

- 👍 …
- 👎 …

### Варіант B

- 👍 …
- 👎 …

## Consequences

- Позитивні: …
- Негативні / що стає складніше: …
- Що треба зробити далі: …
```

## Правила

- ADR без `Consequences` і без плюсів/мінусів кожного варіанта не приймається (DoD, пункт R3).
- Мінімум два розглянуті варіанти.
