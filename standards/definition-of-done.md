# Definition of Done (власний, проєктний)

Доповнює курсовий DoD («з AI»). Зміна (коміт / PR) готова, коли виконано **всі** пункти.

## A. Автоматичні (блокують коміт або push)

| ID  | Умова                                      | Де перевіряється |
| --- | ------------------------------------------ | ---------------- |
| A1  | код відформатовано Prettier                | pre-commit       |
| A2  | ESLint без помилок і без попереджень       | pre-commit       |
| A3  | типи сходяться (`tsc --noEmit`)            | pre-commit       |
| A4  | правила залежностей зі spec не порушено    | pre-push         |
| A5  | smoke-тест проходить                       | pre-push         |
| A6  | проєкт збирається (`npm run build`)        | pre-push         |
| A7  | повідомлення коміту — Conventional Commits | commit-msg       |

## B. Рев'ю (перевіряю я перед merge)

| ID  | Умова                                                                        |
| --- | ---------------------------------------------------------------------------- |
| R1  | зміна відповідає пунктам spec (`AC*` / `D*`), на які вона посилається        |
| R2  | якщо змінилась поведінка/структура — спершу змінено `spec.md`                |
| R3  | ключове рішення має ADR за [шаблоном](adr-template.md)                       |
| R4  | промпти до AI збережено дослівно в `ai/`, коміти з AI мають `Co-Authored-By` |
| R5  | вихід AI прочитано повністю, а не лише перевірено наявність файлів           |
| R6  | у репозиторії немає `node_modules/`, `dist/`, `.env`, PDF                    |
| R7  | історія не переписана після показу (без `--force`)                           |

## C. Завдання курсу

Завдання готове, коли є PR `feat/labN-*` → `main`, `DEFENSE.md` за шаблоном курсу з SHA
комітів, і PR змерджено.
