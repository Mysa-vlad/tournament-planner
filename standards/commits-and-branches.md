# Коміти, гілки, PR

## Коміти — Conventional Commits

```
<type>(<scope>)?: <опис у наказовому способі, англійською або українською>

<тіло: що і чому; посилання на AC*/D* зі spec>

Co-Authored-By: <AI-асистент>   # якщо зміну зроблено з AI
```

Типи: `feat`, `fix`, `refactor`, `docs`, `test`, `build`, `ci`, `chore`, `perf`, `style`.
Перевіряється hook-ом `commit-msg` (DoD A7).

## Гілки

- `main` — завжди зелена, напряму не комітимо (крім першого коміту репозиторію).
- `feat/labN-<тема>` — одна гілка = одне завдання курсу.
- Виправлення за рев'ю попередньої роботи — окрема гілка `fix/labN-<тема>`.

## PR

- Назва = Conventional Commit заголовок.
- В описі: які `AC*` закриває, посилання на `DEFENSE.md`.
- Merge — звичайний merge-коміт (історія ітерацій зберігається, без squash).
